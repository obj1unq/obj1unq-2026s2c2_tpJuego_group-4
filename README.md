Wallaga

Wallaga es un videojuego inspirado en -Galaga- desarrollado en Wollok, utilizando la biblioteca de Wollok Game

El jugador controla una nave espacial que debe enfrentarse a diferentes tipos de enemigos y esquivar sus proyectiles mientras consigue puntos.

## Equipo de desarrollo

- Andrea G. Frank
- Lucas Asorey

## OBJETIVO/REGLAS

El objetivo es eliminar enemigos para conseguir puntos y alcanzar la meta de 5000 para ganar la partida.

El juego cuenta con diferentes tipos de naves enemigas.

-- 

*Tanque*

Tiene 3 vidas

Dispara cada 10 segundos

Otorga 200 puntos al ser destruido

*Ligera*

Tiene 1 vida

Dispara cada 5 segundos

Otorga 500 puntos al ser destruido

*Jefe*

Tiene 5 vidas

Dispara cada 5 segundos

Otorga 1000 puntos al ser destruido

--

El jugador comienza con 3 vidas. Cada vez que recibe un impacto pierde una vida.

El juego cuenta con 2 finales: 

  - El jugador pierde todas sus vidas → Game Over
  - El jugador alcanza la cantidad de puntos necesaria → Victoria

## INSTRUCCIONES/CONTROLES

W = Mover hacia arriba

A = Mover hacia la izquierda

S = Mover hacia abajo

D = Mover hacia la derecha

ESPACIO = Disparar

R = Reiniciar la partida después de perder
